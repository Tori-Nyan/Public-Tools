# Torinyan Public Tools

This collection of tools will contain most of the tools that the Torinyan brand wishes to publicize to its userbase.  
Any tools here should be OK to use however people like.

> [!WARNING]
> Do keep in mind this repository is still being worked on and only visible features should be used for now.

## Create Nice Layer

A handy tool to help users create new layers that don't look like a mess.  
Open via `Tools` / `Torinyan` / `Create Nice Layer`

## Set Anchors

A little component to update the root-bone and/or anchor override values for mesh-objects childed to the component's GameObject.  
This feature relies on a component that can be added via the object component menu `Torinyan` / `Set Anchors`

## Set Bounds

A little component to update the bounds for mesh-objects childed to the component's GameObject.  
This feature relies on a component that can be added via the object component menu `Torinyan` / `Set Bounds`

## Set Menu Icon

This feature relies on a component that can be added via the object component menu `Torinyan` / `Set Menu Icon`
