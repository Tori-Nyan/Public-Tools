# Torinyan Public Tools

This collection of tools will contain most of the tools that the Torinyan brand wishes to publicize to it's userbase.  
Any tools here should be OK to use however people like.

!! Do keep in mind this is repository is still being worked on and only visible features should be used for now.

## Create Nice Layer

A handy tool to help users create new layers that don't look like a mess.  
Open via `Tools` / `Torinyan` / `Create Nice Layer`

## Torinyan Addon

!! Not finished !!

This will be our replacement for MA and Fury when it comes to avatar modularity.  
We have our own vision on how this should be done and wish to bring this to life, for our users to enjoy.  
We didn't want a spiderweb of components and ugly menu structures, or blackbox tools that mess with files and parameters in ways we can't predict.

To realize this, we'll have to make it ourselves. C:

This feature relies on a component which can be added via the object component menu `Torinyan` / `Torinyan Addon`
